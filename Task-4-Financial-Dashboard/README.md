# Task 4: Financial Dashboard

## Project Overview
This project analyzes income, expenses, and financial transactions using Python.

## Features
- Total income and expenses
- Net balance calculation
- Monthly income and expense trends
- Category-wise expense analysis
- Data visualization

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## Dataset
This project uses synthetic sample financial data for demonstration purposes.

## Conclusion
The project demonstrates how financial transaction data can be analyzed to understand spending patterns and monitor income and expenses.
