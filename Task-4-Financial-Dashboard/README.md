# Task 4: Financial Dashboard

## Project Overview
This project summarizes income and expenses using transaction data and visualizations.

## Features
- Total income, total expenses, and net balance summary
- Monthly income and expense trends
- Expense breakdown by category
- Transaction dataset and summary CSV files

## Technologies
Python, Pandas, NumPy, Matplotlib

## Dataset note
The included transaction dataset is **synthetic sample data created for demonstration**, not real personal or financial data. Replace it with the official internship dataset if one was provided.

## Sample summary
- Total income: 4,140,879.42
- Total expenses: 2,764,561.41

These sample figures are for demonstration only.

## Files
- `task4_financial_dashboard.ipynb` — analysis notebook
- `task4_financial_dashboard.py` — Python script
- `financial_transactions.csv` — sample transactions
- `monthly_financial_summary.csv` — month-wise income and expense
- `expense_by_category.csv` — category-wise expenses
- `monthly_income_trend.png` — income trend chart
- `monthly_expense_trend.png` — expense trend chart
- `expense_by_category.png` — category expense chart

## Conclusion
The dashboard analysis illustrates how transaction records can be summarized to monitor income, spending, and net balance.
