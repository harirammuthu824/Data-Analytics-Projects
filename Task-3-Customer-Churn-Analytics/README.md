# Task 3: Customer Churn Analytics

## Project overview
Analyze customer churn using Python, Pandas, NumPy, and Matplotlib.

## Dataset note
This project uses randomly generated **synthetic sample data** for demonstration, not real customer data. If your internship provided an official dataset, use that dataset before submitting findings.

## Sample results
- Customers: 500
- Churned customers: 155
- Overall churn rate: 31.00%
- Month-to-month contract churn rate: 43.08%
- Average tenure: 35.8 months
- Average monthly charges: 69.18

These results apply only to the generated sample and should not be described as real-world findings.
