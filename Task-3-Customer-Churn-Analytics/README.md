# Task 3: Customer Churn Analytics

## Project Overview
This project analyzes customer churn using Python, Pandas, NumPy, and Matplotlib.

## Objectives
- Analyze customer churn and retention.
- Calculate the overall churn rate.
- Compare churn rates across contract types.
- Visualize customer churn using charts.
- Identify key patterns in customer behavior.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## Project Files
- `task3_customer_churn.ipynb` — Python notebook
- `task3_customer_churn.py` — Python script
- `customer_churn_analysis.csv` — Customer dataset
- `churn_by_contract.csv` — Contract-wise churn analysis
- `churn_distribution.png` — Churn distribution chart
- `churn_by_contract.png` — Contract-wise churn chart
- `charges_by_churn.png` — Monthly charges chart

## Dataset Note
This project uses synthetic sample data created for demonstration. The results do not represent real customer data.

## Conclusion
This project demonstrates how Python can be used to analyze customer churn, compare customer groups, and visualize patterns that may support customer retention decisions.
