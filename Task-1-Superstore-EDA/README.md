# Task 1: Exploratory Data Analysis on Superstore Retail Sales

## Objective
Analyze retail sales, profit, monthly trends, product categories, and discount impact.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Project Steps
1. Load the Superstore dataset.
2. Clean missing values and column names.
3. Convert order dates into date format.
4. Analyze monthly sales and profit.
5. Compare sales across categories and regions.
6. Study discount impact on profit.
7. Present five business findings.

## Deliverables
- Cleaned dataset
- Python notebook
- Charts and visualizations
- Five business findings
